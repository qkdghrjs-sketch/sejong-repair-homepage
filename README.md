# 세종수선방아저씨 홈페이지

신발 수선과 칼갈이를 하는 세종수선방아저씨의 한 페이지 홈페이지입니다.
Next.js(App Router) + Tailwind CSS 로 만들었습니다.

## 내용을 고치려면 (개발 지식 없어도 됩니다)

거의 모든 내용이 **두 파일**에 모여 있습니다. 여기만 고치면 화면 전체가 따라 바뀝니다.

| 파일 | 들어 있는 것 |
| --- | --- |
| `src/lib/site.ts` | 상호, 전화번호, 영업시간, 날씨 안내, 위치 안내, 택배 안내, 카카오톡 채널 주소 |
| `src/lib/repairs.ts` | 수선 항목과 가격 |

### 규칙 두 가지

1. **대괄호 `[ ]` 로 감싼 값은 "아직 안 채운 자리"** 입니다.
   화면에 노랗게 표시되고, 검색엔진에 보내는 정보(`/llms.txt`, JSON-LD)에서는 자동으로 빠집니다.
   실제 내용으로 바꾸면 표시가 저절로 사라집니다.
2. **가격을 빈 문자열 `""` 로 두면 화면에 "문의"** 라고 나옵니다.
   지어낸 가격이 손님에게 보이는 일은 없습니다.

### 사진 넣기

`public/img/` 폴더에 사진을 넣고, 해당 구역 파일(예: `src/components/home/AboutSection.tsx`)의
`IMAGE` 값을 파일 경로로 바꾸면 됩니다. 비워두면 사진 자리는 안내 문구로 대체됩니다.

## 화면 구성

한 페이지 스크롤형입니다.

첫 화면 → 왜 고쳐 신는가 → 소개 → 수선 종류 → 가격 → 택배 수선 → 영업시간·문의

- 휴대폰에서는 화면 아래에 **[전화 문의] [카톡으로 견적 문의]** 버튼이 항상 붙어 있습니다.
- 고정된 가게 주소가 없어, 주소가 들어갈 자리는 모두 카카오톡 채널 문의로 연결됩니다.
  나중에 주소가 생기면 `src/lib/site.ts` 의 `address.hasAddress` 를 `true` 로 바꾸고
  주소를 채우면 지도와 주소 표기가 다시 나타납니다.

## 검색·AI 노출

- `/llms.txt` — 챗GPT·클로드 같은 AI가 읽는 가게 요약 (자동 생성)
- JSON-LD (`LocalBusiness`) — 검색엔진에 상호·전화·영업시간·수선 항목을 알려 줍니다
- `/sitemap.xml`, `/robots.txt` — 자동 생성

스크롤 등장 효과는 자바스크립트가 켜져 있을 때만 적용됩니다.
자바스크립트를 실행하지 않는 크롤러에게도 본문이 그대로 보이도록 한 조치입니다.
